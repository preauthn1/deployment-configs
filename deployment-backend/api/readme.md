### Directory tree introduction
```
appsettings-adminsys.json for adminsys
appsettings-game.json for game
appsettings-public.json for public
appsettings-vendor.json for vendor
Chart.yaml for Chart infomation
values.yaml for instance information
templates/* for infrastructure code template
```
values.yaml 內的資訊可以在 helm upgrade/install 的時候 set 進去
